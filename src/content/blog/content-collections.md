# Content Collections

Las Content Collections permiten organizar contenido como datos.

En lugar de tener cada artículo directamente dentro de
`src/pages`, podemos almacenarlos dentro de:

`src/content/blog`

Después podemos consultarlos utilizando `getCollection()`.
