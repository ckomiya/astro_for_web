# Introducción a Astro

Astro es un framework orientado principalmente a sitios web
centrados en contenido.

Su filosofía busca enviar la menor cantidad posible de JavaScript
al navegador.

## Conceptos aprendidos

- Componentes
- Routing
- Layouts
- Islands Architecture
- Content Collections
